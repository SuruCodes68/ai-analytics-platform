
# AI-Powered Data Analytics Platform

An AI-driven analytics application combining automated exploratory data analysis, machine learning, and conversational AI to streamline data exploration and predictive modeling.

## Live Application

[Launch AI Analytics Platform](https://suranjana-analytics-app.streamlit.app/)

## Key Capabilities

- Automated exploratory data analysis (EDA)
- Machine learning model selection and evaluation
- AI-powered analytical assistance using LangChain
- Interactive data analysis through Streamlit

Python | Pandas | Scikit-learn | LangChain | Gemini | Streamlit
